# Demo brief: AI-powered product automation specialist

This sanitized brief explains why this demo exists. It is not a proposal, application, or representation of production delivery.

## Requested capability

Build and automate AI-powered products and workflows using generative AI, LLMs, retrieval, AI agents, intelligent data pipelines, business-process automation, existing-system integrations, and reliable production-oriented applications.

## Relevant requested examples

- Configure a headless Mac mini with secure remote access, backups, encryption, and local tooling.
- Install and configure n8n, Pinokio, and Ollama.
- Connect Slack, Microsoft 365, Salesforce, Twilio, web-monitoring tools, and Google Workspace.
- Work with LLM APIs, OAuth, and API credentials.
- Build website visitor identification using JavaScript tracking, reverse-IP enrichment, behavioral scoring, and CRM integration.
- Build public-web monitoring workflows that surface buying signals.
- Document the system for a nontechnical operator.

## MVP mapping

This demo implements one narrow scenario: website visitor behavior is received, scored with explainable rules, checked for duplicate handling, and presented as a lead action. Salesforce, Slack, web crawling, email, OpenRouter, and local-model integrations are adapter boundaries or mock services in this MVP.

## Not implemented

- No production Salesforce account or credentials.
- No production Slack, Twilio, Microsoft 365, Google Workspace, or email sending.
- No crawler credential or real reverse-IP provider.
- No Ollama or Mac Mini deployment yet.
- No automated outbound sales messages.
- No claim of production security, deliverability, scale, or model accuracy.
